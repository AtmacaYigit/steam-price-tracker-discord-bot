# 🎮 Steam Discount Tracker Discord Bot

A lightweight Python automation bot that tracks Steam game prices using the official Steam Storefront API and sends detailed, rich embedded notification cards to a Discord channel when discounts occur.

## ✨ Features

* Real-time price and discount tracking via official Steam API
* Rich Discord Embed notifications (game banner, current price, original price, discount percentage, and store redirect link)
* Smart filtering to trigger alerts only when a discount is detected
* Easy configuration to monitor multiple games using Steam App IDs

## 🚀 Installation & Usage

1. Clone the repository:
git clone https://github.com/AtmacaYigit/steam-price-tracker-discord-bot.git

2. Navigate to project folder:
cd steam-price-tracker-discord-bot

3. Install the required dependency:
pip install requests

4. Configure your Discord Webhook URL and App IDs in steam_tracker.py

5. Run the script:
python steam_tracker.py
